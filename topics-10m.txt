# Topics for the 10M build. 1121 topics, every one measured against
# Commons before it was allowed in.
#
# MEASURED 2,115 candidate strings via list=search totalhits (filetype:bitmap).
# The previous 1,200-topic draft had a median of 919 hits and 50% of its topics
# under 1,000 -- it projected to ~3.5M indexed, not 10M, because Cirrus ANDs
# terms and a 3-4 word phrase retrieves almost nothing ("silicon wafer rainbow"
# = 1 file, "anechoic chamber wedges" = 1). Topics under 2,000 hits were
# replaced with measured alternatives in the same section.
# Projection with the same model: 3,530,221 -> 9,735,973 indexed.
#
# HOW TO ADD A TOPIC: measure it first. Anything under 2,000 bitmap hits is
# not worth a crawl slot. Prefer one- and two-word concrete nouns; Commons is
# deep on places, species, buildings, vehicles and objects, and shallow on
# art-directed scene descriptions.
#
# DEPTH IS NOT CAPPED AT 10,000. The search API refuses offsets past 10k, but
# filew: shards a query disjointly -- measured: sunset+CC-Zero = 21,179, of
# which filew:>3000 = 17,186 and filew:<3000 = 4,193. Split any (topic,licence)
# shard by width band until each piece is under 10k and the whole clean pool is
# reachable. Licence categories shard it 8 ways first (see allocation.html 6).
#
# Class F (F1/F2) is EXEMPT from the hits floor: those topics are harvested from
# Openverse/Flickr/Rawpixel, not Commons, so a Commons hit count says nothing
# about them (allocation.html 7 measured Commons plates supply at ~zero).
#
# Supersedes seeds.txt (written for a 25k prototype) for everything 10M.
# Grouped by allocation class (11); class targets are spending caps (12):
# write topics until each class has enough, then let the relevance gate (13)
# decide how deep each one goes. Bucket sizes are budgets, not quotas (5).
#
# Rules: concrete search strings, lowercase ASCII, single spaces, no modifier
# cross-product ('forest' + 'forest macro' return overlapping results and waste
# budget). Proper nouns are wanted (hybrid BM25 beats dense-only on names).
# Class C is PD-framed (dead 100+ years, pre-1930s decades) to suit its licence
# shard; the shard still filters, topics only lean.
# The cutouts section of seeds.txt is dropped entirely (10: refuse the cutout).
